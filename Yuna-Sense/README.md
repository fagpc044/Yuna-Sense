# 🌙 Yuna Sense

> Aplicação web desenvolvida com Python e Flask, com sistema de usuários e interação com um chatbot.

## 📌 Sobre o projeto

O **Yuna Sense** é uma aplicação web desenvolvida como projeto acadêmico, utilizando **Python e Flask** no Back-End.

O projeto foi desenvolvido com o objetivo de aplicar na prática conceitos de desenvolvimento web, gerenciamento de usuários, banco de dados e integração entre Back-End e Front-End.

## 🚀 Funcionalidades

- 👤 Cadastro de usuários
- 🔐 Login e logout
- 🔒 Sistema de sessão
- 👤 Perfil personalizado
- 💬 Chatbot
- 🗄️ Armazenamento de dados em banco de dados
- 📊 Histórico de informações do usuário
- 🖼️ Upload de imagem de perfil
- 🌐 Interface web responsiva

## 🛠️ Tecnologias utilizadas

### Back-End

- 🐍 Python
- 🌐 Flask
- 🗄️ SQLAlchemy
- 💾 SQLite

### Front-End

- 🌐 HTML
